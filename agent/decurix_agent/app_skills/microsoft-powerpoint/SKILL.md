Which PowerPoint. "PowerPoint (Host)" is Microsoft PowerPoint on the person's computer, shown in a window of this
desktop: it saves the person's files (C:\...). A deck to make in this desktop's work folder is made in LibreOffice
Impress instead (see libreoffice-impress).

How PowerPoint is worked here
- Ribbon tabs and buttons are pressed by their refs; Alt key-tips do not work. Ctrl shortcuts do (Ctrl+M new slide,
  Ctrl+S, F12).
- A dialog's drop-down is set with gui select REF "entry".

Building a deck
- From the start screen press "Blank Presentation". The first slide is a Title Slide: type the title into the
  "Click to add title" box and the subtitle into "Click to add subtitle", each by its ref.
- New slide: tab "Home", button "New Slide" (or Ctrl+M) gives "Title and Content": type the title, then the bullets as
  lines of one gui type into the content box.
- A table: on the slide's content box press the "Insert Table" icon, or tab "Insert", button "Table", then
  "Insert Table..." (with the menu open, the key i chooses it) and set columns and rows. A new table is selected as a
  whole, not being edited: text typed now goes nowhere ("nothing visible changed"). Click inside the first cell
  (the top-left of the table, by its point), then gui type the first value, gui key Tab, gui type the next, and so on
  row by row; each typing shows a "Language ..." button appearing when it landed. Tab in the last cell adds a row.
- Read each slide back after typing: its texts are listed by gui observe.

Saving
- F12 opens Save As: type the whole path and name into "File name" (C:\Users\...\deck.pptx), set "Save as type" with
  gui select to "PowerPoint Presentation", read both back, press "Save". The title shows the new name.
